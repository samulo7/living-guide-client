# 🏙️ 躺平指南 (Living Guide Client)

> 面向旅居与数字游民的城市决策与落地协作应用。

## ✨ 项目简介

「躺平指南」面向旅居与数字游民，解决“信息多但决策难”的选城问题。项目不做短期打卡攻略，而聚焦长期停留，把居住成本、岗位机会与社交连接放在同一决策链路，帮助用户在迁移前降低试错成本。

业务主线按“选城-落地-生存-连接”展开：首页负责城市筛选与详情；`安家大厅` 提供房源列表、详情与收藏；`搞钱大厅` 提供岗位列表与详情；`搭子广场` 支持发布、编辑、完结；`用户中心` 承接个人资料、我的收藏与发布。

技术上采用前后端一体仓库：前端基于 `uni-app x + Vue 3 + UTS`，支持 H5 与多端构建；后端基于 `Express + MySQL`，通过 `/api/*` 提供业务接口。鉴权采用 JWT：登录后保存 token，请求携带 Bearer token，接口 401 时自动清理会话并跳转登录页。

工程侧强调单仓协作与可扩展：前端集中管理 API 基址与请求拦截，后端按 `auth/user/cities/houses/jobs/social` 分模块路由。当前版本已覆盖城市、房源、岗位、社交、用户主链路，可继续迭代治理与跨端体验。

## 核心功能

- **城市选择**：城市列表筛选、搜索、详情查看。
- **安家大厅**：房源列表、房源详情、收藏/取消收藏。
- **搞钱大厅**：岗位列表、岗位详情、职位状态处理。
- **搭子广场**：帖子发布、编辑、完结、删除与详情查看。
- **用户中心**：个人资料、我的收藏、我的发布聚合展示。

## 🛠️ 技术栈

- **前端**：`uni-app x`、`Vue 3`、`UTS`
- **后端**：`Node.js`、`Express`、`MySQL`
- **鉴权**：`JWT` (`Authorization: Bearer <token>`)
- **开发形态**：前后端同仓协作（monorepo）

## 🚀 快速开始

### 1. 启动前端（H5）

```bash
npm install
npm run dev:h5
```

### 2. 启动后端

```bash
cd server
npm install
npm run dev
```

默认本地接口地址为 `http://localhost:3000`。
