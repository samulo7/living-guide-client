# 🏕️ 躺平指南 App - V3.3 搭子副本 (社交广场)

## 🎯 任务目标
在底部的【搭子】Tab 中，开发一个轻社交信息流。展示用户发布的找搭子需求，采用类似社区动态/朋友圈的卡片流设计，增强 App 的社区粘性。

## 🛠️ 具体开发需求

### 1. 后端新增搭子接口
**文件**: `server/src/routes/companion.js` (新建文件) & `app.js` (或入口文件)
* **新建路由**：实现 `GET /` 接口，从 `companions` 表查数据。
* **排序**：按发布时间倒序排列 `ORDER BY created_at DESC`。
* **路由挂载**：在主入口中挂载到 `/api/companions`。

### 2. 前端开发【搭子广场】页面
**文件**: `pages.json` 里的对应页面 (假设为 `pages/social/index.uvue` 等，请查阅 tabBar 配置)
* **数据请求**：页面 `onLoad` 时请求 `/api/companions`。
* **UI 头部设计**：
  * 大标题：`搭子广场`
  * 副标题：`一个人躺平太无聊？找个同频搭子`
* **动态卡片设计**：
  * **发帖人信息区**：左侧一个圆形的默认头像，右侧上方是 `nickname`，下方是浅色的 `📍 {{ city_name }} · 发布于 {{ created_at }}`。
  * **核心招募区**：加粗的大字体 `title`。
  * **详情描述**：正常的灰色正文 `content`。
  * **标签区**：将 `tags` 按逗号分割，渲染成彩色圆角小标签（例如“饭搭子”可以用橘色，“社恐友好”可以用绿色）。
