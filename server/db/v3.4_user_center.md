# 👤 躺平指南 App - V3.4 个人中心 (我的)

## 🎯 任务目标
完善底部最后一个 Tab【我的】。展示用户的基本个人信息，并打通“我的收藏”功能，展示用户收藏的房源列表。**注意：作为 MVP 版本，当前不涉及真实登录，后端接口默认写死返回 user_id = 1 的数据。**

## 🛠️ 具体开发需求

### 1. 后端新增 User 接口
**文件**: `server/src/routes/user.js` (新建文件) & `app.js` (或入口文件)
* **获取用户信息**：`GET /profile`。直接 `SELECT * FROM users WHERE id = 1`。
* **获取收藏列表**：`GET /favorites`。通过 `user_id = 1` 去 `favorites` 表中查出对应的 `house_id`，然后 `JOIN houses` 和 `JOIN cities`，返回完整的房源信息列表（字段格式须与安家大厅一致）。
* **挂载路由**：在主入口中将该路由文件挂载到 `/api/user`。

### 2. 前端开发【我的】页面
**文件**: `pages.json` 里的对应页面 (假设为 `pages/user/user.uvue` 或 `index.uvue`，请查阅 tabBar 配置)
* **数据请求**：页面 `onLoad` 时，分别请求 `/api/user/profile` 和 `/api/user/favorites`。
* **UI 头部设计 (个人资料区)**：
  * 左侧大号圆形头像（缺省用灰色占位图）。
  * 右侧展示加粗的 `nickname` 和浅色的个性签名 `bio`。
  * 整个头部可以加一个淡淡的绿色渐变背景，呼应 App 的主题色。
* **UI 数据面板 (横向菜单)**：
  * 横向排列三个小模块：`我的发布 (2)`、`我的收藏 (2)`、`浏览记录 (18)`。数字可先写死或绑定数组长度。
* **UI 收藏列表区**：
  * 标题：`我的收藏`。
  * 列表渲染：复用【安家大厅】里极其精美的房源卡片设计（带图片、红字价格、城市名、高亮标签等），遍历渲染获取到的收藏房源数据。
